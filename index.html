Voice installed, but still no sound?

Changing the Windows narrator voice does not select this website’s voice. Choose Microsoft Hanhan, Yating, or Zhiwei (zh-TW) in the menu above, then tap Try 你好.

  1. Fully exit your browser, including background windows, then reopen it. If necessary, restart Windows once after installing the voice.
  2. Reload this page with Ctrl+F5. Choose Reset voice selection, then Check voices again.
  3. Open the site in a normal, updated Edge or Chrome browser window, not an embedded preview. Check the tab isn’t muted, Windows Volume Mixer, and your speaker/headphone output.
  4. Try another installed Taiwan voice. If none work, test the voice in Windows Speech settings to check the installation itself.

Need a voice? Follow the installation guide

Install Taiwan Mandarin on Windows

  1. Open Settings → Time & Language → Speech.
  2. Under Manage voices, choose Add voices. Select Chinese (Traditional, Taiwan), then Add. Names may include Hanhan, Yating, or Zhiwei, depending on Windows.
  3. If it isn’t listed, open Language / Language & region → Add a language, add Chinese (Traditional, Taiwan), and install its Text-to-speech / Speech language feature. You don’t need to change your Windows display language.
  4. Wait for the download, fully close and reopen your browser, then select Check voices again here.

Set up Mandarin on Android

  1. In Settings, search for Text-to-speech output (often under Accessibility or Languages & input).
  2. Open your preferred speech engine’s settings, then Install voice data. Download Chinese / Mandarin; choose Taiwan if offered.
  3. Restart your browser, then tap Check voices again.

Names vary by manufacturer and speech engine. Not every Android device offers a Taiwan voice or exposes downloaded voices to the browser.

Set up Mandarin on iPhone / iPad

  1. Open Settings → Accessibility → Spoken Content (called Read & Speak on some versions) → Voices.
  2. Choose Chinese, then a Chinese (Taiwan) voice if offered. Tap the download icon.
  3. Reopen Safari, return here, and tap Check voices again.

Availability in websites varies by iOS version. A downloaded accessibility voice is not guaranteed to appear in every browser.

Set up Mandarin on Mac

  1. Open System Settings → Accessibility → Spoken Content (or Read & Speak).
  2. Open the system voice menu and Manage Voices. Download a Chinese (Taiwan) voice if offered.
  3. Reopen your browser, then tap Check voices again.

Menu names and browser voice availability vary by macOS version.

This website cannot install system voices for visitors. Audio uses your device’s speech service, not native-speaker recordings. Some voices need internet access and may process text through their provider. We do not record your microphone or grade your accent. If audio isn’t available, keep practicing with Pinyin and translations.
